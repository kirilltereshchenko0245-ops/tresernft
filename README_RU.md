# Telegram NFT Gift Tracker (starter)

Парсер выставленных за Telegram Stars подарков с публикацией новых объявлений в темы форум-группы.

## Переменные окружения

Скопируйте `.env.example` в `.env` и заполните:

- `API_ID` — Telegram API ID с https://my.telegram.org
- `API_HASH` — Telegram API Hash с https://my.telegram.org
- `BOT_TOKEN` — токен бота от @BotFather
- `GROUP_ID` — числовой ID форум-супергруппы, например `-1001234567890`
- `POLL_INTERVAL` — интервал опроса в секундах (по умолчанию 60)
- `SESSION_NAME` — имя MTProto session-файла
- `GIFT_IDS` — необязательный список ID типов подарков через запятую
- `SEED_EXISTING` — `true`, чтобы при первом запуске не публиковать старые объявления
- `MAX_PAGES_PER_GIFT` — ограничение страниц на тип подарка за цикл
- `LOG_LEVEL` — уровень логирования

## Запуск на сервере

1. Загрузите ZIP и распакуйте проект.
2. Скопируйте `.env.example` в `.env` и заполните переменные.
3. Установите зависимости: `pip install -r requirements.txt`
4. Запустите `python app.py` из интерактивного терминала для первой авторизации MTProto. Введите номер телефона и код Telegram, если потребуется.
5. Убедитесь, что бот добавлен в форум-группу и имеет права управлять темами и отправлять сообщения.
6. После успешной авторизации перезапустите процесс под менеджером процессов или используйте Docker Compose: `docker compose up -d --build`.

**Важно:** храните `.env` и `*.session` в секрете. Не загружайте их в публичные репозитории и не отправляйте посторонним.

## Перед боевым использованием

Telegram регулярно меняет TL-схему. Текущая версия — стартовый проект, который необходимо проверить на реальном аккаунте: поля цены/уникального экземпляра и пагинация могут отличаться от ожидаемых. Убедитесь, что ключ `listing_key` действительно уникален для отдельного листинга. Ссылка `https://t.me/nft/<slug>` формируется только если API вернул slug и должна быть проверена на реальном объекте. Начните с `POLL_INTERVAL=60`, `MAX_PAGES_PER_GIFT=1` и тестовой группы.
