# Telegram NFT Gift Tracker (starter)

Парсер выставленных за Telegram Stars подарков с публикацией новых объявлений в темы форум-группы.

## ⚠️ ВАЖНО: Требуется пользовательский аккаунт

API метод `GetResaleStarGiftsRequest` **НЕ работает с ботами** - это ограничение Telegram. Приложение должно работать от имени пользовательского аккаунта (userbot).

**См. подробную инструкцию в файле [SETUP_RU.md](SETUP_RU.md)**

## Переменные окружения

Скопируйте `.env.example` в `.env` и заполните:

- `API_ID` — Telegram API ID с https://my.telegram.org
- `API_HASH` — Telegram API Hash с https://my.telegram.org  
- `BOT_TOKEN` — токен бота от @BotFather (используется только для публикации)
- `PHONE_NUMBER` — ваш номер телефона (нужен только для первой авторизации локально)
- `GROUP_ID` — числовой ID форум-супергруппы, например `-1001234567890`
- `POLL_INTERVAL` — интервал опроса в секундах (по умолчанию 60)
- `SESSION_NAME` — имя MTProto session-файла
- `GIFT_IDS` — необязательный список ID типов подарков через запятую
- `SEED_EXISTING` — `true`, чтобы при первом запуске не публиковать старые объявления
- `MAX_PAGES_PER_GIFT` — ограничение страниц на тип подарка за цикл
- `LOG_LEVEL` — уровень логирования
- `DB_PATH` — необязательный путь к SQLite (по умолчанию `data/gifts.db`)

## Данные владельца NFT

Парсер читает только поля, которые Telegram вернул в ответе `GetResaleStarGiftsRequest`: `owner_id`, `owner_name`, `owner_address` и отдельно `host_id`. Если Telegram не передал владельца, трекер не пытается обходить настройки приватности и показывает «Telegram не раскрыл данные». Username добавляется только если Telegram включил соответствующего пользователя в `users` ответа и вернул публичный username. Старые записи SQLite автоматически дополняются новыми колонками.

## Быстрый старт

### 1. Локальная авторизация (на вашем компьютере)

```bash
# Установите зависимости
pip install -r requirements.txt

# Настройте .env с вашим PHONE_NUMBER
cp .env.example .env
nano .env  # заполните все поля, включая PHONE_NUMBER

# Запустите для первой авторизации
python app.py
# Введите код из Telegram когда попросит
```

После успешной авторизации будет создан файл `tracker_session.session`.

### 2. Деплой на сервер (Fadehost или другой хостинг)

```bash
# Загрузите файл tracker_session.session на сервер
# В .env на сервере оставьте PHONE_NUMBER пустым!

# Используйте Docker
docker compose up -d --build
```

## Запуск на сервере без Docker

1. Загрузите ZIP и распакуйте проект
2. Скопируйте `.env.example` в `.env` и заполните переменные
3. Установите зависимости: `pip install -r requirements.txt`
4. Загрузите файл `.session` созданный локально
5. Убедитесь, что бот добавлен в форум-группу и имеет права управлять темами и отправлять сообщения
6. Запустите: `python app.py`

**Важно:** храните `.env` и `*.session` в секрете. Не загружайте их в публичные репозитории и не отправляйте посторонним.

## Перед боевым использованием

Telegram регулярно меняет TL-схему. Текущая версия — стартовый проект, который необходимо проверить на реальном аккаунте: поля цены/уникального экземпляра и пагинация могут отличаться от ожидаемых. Убедитесь, что ключ `listing_key` действительно уникален для отдельного листинга. Ссылка `https://t.me/nft/<slug>` формируется только если API вернул slug и должна быть проверена на реальном объекте. Начните с `POLL_INTERVAL=60`, `MAX_PAGES_PER_GIFT=1` и тестовой группы.
