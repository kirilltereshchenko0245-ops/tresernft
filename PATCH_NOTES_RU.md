# Что изменено в версии с данными владельца

- Парсер учитывает `StarGiftUnique`, включая поля `owner_id`, `owner_name`, `owner_address` и `host_id`.
- Публичный username разрешается только по объектам `users`/`chats`, которые Telegram вернул вместе со страницей.
- `host_id` отображается отдельно и не называется владельцем.
- В карточку объявления добавлены строки владельца и, если доступен, TON-адрес.
- SQLite автоматически мигрирует старую таблицу `listings` и сохраняет публичные сведения о владельце.
- Для уже известных объявлений поля владельца обновляются без повторной публикации сообщения.
- Если Telegram не передал данные владельца, трекер явно сообщает об этом. Скрытые профили не обходятся.

## Важное ограничение

`owner_id`, `owner_name`, `owner_address` и `host_id` — опциональные поля Telegram. Наличие полей в TL-схеме не означает, что Telegram передаст их для каждого подарка. Если `owner_id` отсутствует, получить username из одного slug надёжным штатным способом нельзя.
