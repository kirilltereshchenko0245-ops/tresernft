# Инструкция по настройке

## Проблема с авторизацией

API метод `GetResaleStarGiftsRequest` **не работает с ботами** - это ограничение Telegram API. Вам нужно использовать **пользовательский аккаунт (userbot)**.

## Решение: Создание файла сессии локально

### Шаг 1: Настройка локально на вашем компьютере

1. Установите зависимости:
```bash
pip install -r requirements.txt
```

2. Создайте файл `.env` на основе `.env.example`:
```bash
cp .env.example .env
```

3. Заполните `.env`:
```env
API_ID=ваш_api_id
API_HASH=ваш_api_hash
BOT_TOKEN=ваш_bot_token
PHONE_NUMBER=+79001234567  # Ваш номер телефона
GROUP_ID=-1001234567890
SESSION_NAME=tracker_session
```

4. Запустите приложение локально:
```bash
python app.py
```

5. Введите код подтверждения из Telegram, который придёт вам в сообщениях

6. После успешной авторизации будет создан файл `tracker_session.session`

### Шаг 2: Загрузка сессии на сервер

1. Загрузите файл `tracker_session.session` на ваш сервер Fadehost (в ту же папку где app.py)

2. Обновите `.env` на сервере:
```env
API_ID=ваш_api_id
API_HASH=ваш_api_hash
BOT_TOKEN=ваш_bot_token
PHONE_NUMBER=  # Оставьте пустым!
GROUP_ID=-1001234567890
SESSION_NAME=tracker_session
```

3. Перезапустите контейнер - теперь он будет использовать существующую сессию без интерактивного ввода

## Важно

- **НЕ ДЕЛИТЕСЬ** файлом `.session` - это полный доступ к вашему Telegram аккаунту!
- Добавьте `*.session` в `.gitignore` (уже добавлено)
- Файл сессии действителен до тех пор, пока вы не завершите сеанс в настройках Telegram

## Альтернатива (не рекомендуется для продакшена)

Можно оставить `PHONE_NUMBER` в `.env` на сервере, но при первом запуске контейнер будет ждать интерактивного ввода кода подтверждения, что невозможно в автоматическом режиме Fadehost.
